 PAIRING CODE
━━━━━━━━━━━━━━━━━━

Pengaturan Pairing Code berada di file:

config.js

Cari bagian:

global.pairing

Lalu isi dengan nomor WhatsApp yang ingin digunakan untuk login bot.

Contoh:

global.pairing = '628xxxxxxxxxx'

Gunakan format nomor:

628xxxxxxxxxx

Jangan gunakan:

+628xxxxxxxxxx
08xxxxxxxxxx

Setelah nomor diisi, jalankan bot dan ikuti proses Pairing Code yang muncul di terminal.

 THUMBNAIL MENU
━━━━━━━━━━━━━━━━━━

Mau ganti gambar menu?

Gampang.

Kirim atau reply foto lalu ketik:

.setthumbmenu

Bot bakal nyimpan foto tersebut sebagai thumbnail menu.

━━━━━━━━━━━━━━━━━━
 AUDIO MENU
━━━━━━━━━━━━━━━━━━

Mau ganti sound menu?

Reply audio atau VN lalu ketik:

.setaudio

Audio bakal dipake buat menu bot.

Disarankan:
• Durasi pendek
• Tidak terlalu besar
• Format MP3 / Audio WhatsApp

 NODEJS YANG DISARANKAN
━━━━━━━━━━━━━━━━━━

Gunakan:

✓ NodeJS v20
✓ NodeJS v21

Tidak disarankan:

✗ NodeJS terlalu lama
✗ NodeJS modifikasi aneh-aneh

Cek versi:

node -v

━━━━━━━━━━━━━━━━━━
 SEBELUM MENJALANKAN BOT
━━━━━━━━━━━━━━━━━━

Pastikan seluruh module sudah terpasang.

Jalankan perintah berikut:

npm install

Setelah proses selesai, jalankan bot dengan:

npm start

Jika terjadi error saat startup, pastikan semua module berhasil terinstall dan versi NodeJS yang digunakan sudah sesuai.

 JIKA BOT FORCE CLOSE
━━━━━━━━━━━━━━━━━━

Biasanya karena:

• Module rusak
• Syntax error
• RAM habis
• Versi NodeJS tidak cocok

Jangan cuma kirim:

"Bang error"
